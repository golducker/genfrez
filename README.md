# GenFreZ — Your Green Reward Platform

Hackathon site for GenFreZ (FTU-UQ i-HONS Business Hackathon 2026). Points for green behaviour in Hanoi, priced in avoided CO₂.

- `frontend/` — Next.js site (home, about, solution, contact). Deployed on Vercel, root `frontend/`.
- `backend/` — Express API (contact form, stats, points calculator). Deployed on Vercel, root `backend/`.
- Live demo of the Zalo Mini App: https://hackathon-i-hons-msop.vercel.app/

```bash
cd frontend && npm install && npm run dev   # http://localhost:3000
cd backend  && npm install && npm run dev   # http://localhost:4000
```
